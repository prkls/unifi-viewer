UniFi Viewer

Your Protect cameras, one click away in the menu bar.

A borderless window on your UniFi Protect cameras for macOS. Up to ten named feeds, switched with a number key or a right-click menu. It talks to your Protect console directly over your network and sends nothing anywhere else.

Download for macOS

Apple Silicon. Open it, drag it to Applications, done.

What it does

  • A lens icon sits in your menu bar. Click it to open the cameras on that screen, click again to close.
  • Closing stops the stream, so a closed viewer uses no network and no processor time.
  • ⌃⌥⌘U opens and closes it from any app, without touching the mouse.
  • Number keys switch cameras. Each screen remembers where you put the window and how large you made it.
  • The window has no title bar and stays on top, so it sits wherever you want it while you work.

What you need

  • A Mac with Apple Silicon.
  • A UniFi Protect console on the same network.
  • The stream link for each camera, from Protect: click the camera, Settings, Share Livestream, turn on Secure RTSPS Output. The app asks for these the first time it runs.

Build it yourself

It is a small pile of shell, Swift and a copy of mpv, all on GitHub. To build your own copy: 

git clone https://github.com/prkls/unifi-viewer.git
cd unifi-viewer
brew install mpv
./make-app.sh /Applications

The README covers configuring feeds, the keyboard shortcut, how window placement is remembered, and why it uses the stream endpoint it does.
